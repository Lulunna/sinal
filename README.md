# Sinal

Feed pessoal de notícias de tecnologia. Você cadastra sites e temas de interesse, o n8n coleta todo dia, o Python filtra e ordena por relevância, a IA (Gemini) resume, e tudo vai para o banco de dados. O site tem feed com filtros, favoritos e "ler depois", e uma aba **Bastidores** com custo, tempo e erros das chamadas de IA, além de teste A/B de prompts.
